# Сервис управления рассылками сообщений

Веб-приложение на Django для управления email-рассылками с 
возможностью регистрации пользователей, 
управления клиентами и сообщениями, а также просмотра статистики.

## Основные функции

### 1. Управление клиентами
- Добавление новых получателей рассылки
- Просмотр списка клиентов
- Редактирование существующих клиентов
- Удаление клиентов

### 2. Управление сообщениями
- Создание шаблонов сообщений
- Просмотр списка сообщений
- Редактирование сообщений
- Удаление сообщений

### 3. Управление рассылками
- Создание новых рассылок
- Просмотр списка рассылок
- Редактирование параметров рассылки
- Удаление рассылок
- Ручной запуск рассылки

**Статусы рассылки:**
- Создана - рассылка создана, но не отправлялась
- Запущена - рассылка активна (хотя бы одно сообщение отправлено)
- Завершена - время рассылки истекло

## Расширенная функциональность

### Система аутентификации
- Регистрация с подтверждением email
- Вход/выход из системы
- Восстановление пароля
- Защита от несанкционированного доступа

### Статистика и отчеты
- Количество успешных/неуспешных попыток рассылки
- Общее количество отправленных сообщений
- Графики и диаграммы активности

### Система ролей и прав доступа

**Пользователь:**
- Управление своими клиентами и рассылками
- Просмотр статистики по своим рассылкам

**Менеджер:**
- Просмотр всех клиентов и рассылок
- Просмотр списка пользователей
- Блокировка пользователей

### Оптимизация производительности
- Серверное кеширование
- Клиентское кеширование
- Оптимизированные запросы к БД

## Технологический стек
- **Backend**: Django, Django REST Framework
- **Frontend**: HTML5, CSS, JavaScript, Bootstrap
- **База данных**: PostgreSQL
- **Кеширование**: Redis

## Настройка переменных окружения (.env)

Создайте файл `.env` в корне проекта и укажите следующие параметры:

### Основные настройки Django
- **SECRET_KEY** - Секретный ключ Django для криптографической подписи.  
  Пример: `django-insecure-ваш-уникальный-ключ-из-50-символов`  
  *Никогда не используйте в продакшене ключ из примеров!*

- **DEBUG** - Режим отладки (True/False).  
  В разработке используйте `True`, в продакшене обязательно `False`  
  Пример: `DEBUG=True`

### Настройки базы данных (PostgreSQL)
- **DB_NAME** - Название базы данных  
  Пример: `mailing_db`

- **DB_USER** - Имя пользователя БД  
  Пример: `mailing_user`

- **DB_PASSWORD** - Пароль пользователя БД  
  Пример: `Str0ngP@ssw0rd`

- **DB_HOST** - Хост базы данных  
  Для локальной разработки: `localhost` или `127.0.0.1`  
  Для продакшена: адрес вашего DB-сервера

- **DB_PORT** - Порт базы данных  
  Стандартный порт PostgreSQL: `5432`

### Настройки email-рассылки
- **EMAIL_HOST** - SMTP-сервер для отправки почты  
  Примеры:  
  - Для Yandex: `smtp.yandex.ru`  
  - Для Gmail: `smtp.gmail.com`  
  - Для Mail.ru: `smtp.mail.ru`

- **EMAIL_PORT** - Порт SMTP-сервера  
  Обычно:  
  - TLS: `587`  
  - SSL: `465`

- **EMAIL_HOST_USER** - Email для авторизации на SMTP  
  Пример: `your.email@example.com`

- **EMAIL_HOST_PASSWORD** - Пароль для SMTP (часто это специальный "пароль приложения")  
  *Не используйте основной пароль от email!*

- **EMAIL_USE_TLS** - Использовать TLS шифрование (True/False)  
  Рекомендуется `True` для безопасности

- **EMAIL_USE_SSL** - Использовать SSL шифрование (True/False)  
  Альтернатива TLS, обычно не используют одновременно с TLS  
  Для Gmail: `True`, порт `465`
